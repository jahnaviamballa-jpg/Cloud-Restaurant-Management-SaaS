# Render Notes

## What is Render?
Render is a cloud platform used to deploy web applications easily.

## Deploy React App
Connect the GitHub repository and deploy the frontend as a Static Site.

## Deploy FastAPI App
Deploy the backend as a Web Service using the FastAPI application.

## PostgreSQL Hosting
Render provides managed PostgreSQL databases.

## Environment Variables
Environment variables store sensitive configuration such as database URLs and secret keys.

## Auto Deploy
Render automatically redeploys the application whenever changes are pushed to GitHub.
