# Cloud Deployment Plan

## Frontend Hosting
The frontend will be deployed on Render.

## Backend Hosting
The backend API will also be deployed on Render.

## Database Hosting
The PostgreSQL database will be hosted on Render PostgreSQL.

## Domain
The application can use a custom domain if required.

## SSL
Render automatically provides HTTPS using SSL certificates.

## Auto Deploy
Whenever new code is pushed to GitHub, Render automatically deploys the latest version.
