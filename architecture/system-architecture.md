## Components Explanation

### React Frontend
Provides user interface for customers and restaurant staff.

### FastAPI Backend
Handles APIs, authentication, business logic, and communication.

### PostgreSQL Database
Stores users, restaurants, menus, orders, and inventory data.

### AI Prediction Module
Provides intelligent predictions and analytics.

### Render Cloud
Hosts frontend, backend, and deployment services.
