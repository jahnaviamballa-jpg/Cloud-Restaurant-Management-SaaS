## Authentication Flow

User logs in through frontend.
JWT token is generated by backend.
Authenticated requests access protected APIs.


## API Communication

Frontend communicates with backend using REST APIs.


## Cloud Infrastructure

Frontend and backend are deployed using Render.
Database is hosted using PostgreSQL cloud service.
## Components Explanation

### React Frontend
Provides user interface for customers and restaurant staff.

### FastAPI Backend
Handles APIs, authentication, business logic, and communication.

### PostgreSQL Database
Stores users, restaurants, menus, orders, and inventory data.

### AI Prediction Module
Provides intelligent predictions and analytics.

### Render Cloud
Hosts frontend, backend, and deployment services.
